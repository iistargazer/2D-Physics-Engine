Controls & how to read the experiment

Drag with the primary pointer. Select + Box or + Circle, then click the canvas; select the same tool again to return to dragging. Changing experiments clears your tools and restarts the world.

1–9 / 0 select experiments · Space pause · N single step · D contacts · G position correction · S sleeping · P stage profile. Restart rewinds the current experiment. Step while paused for a precise view.

Awake body Sleeping body Static geometry. Contact dots and lines show where the solver applies normal impulses. Curves in the cradle are constraint guides, not extra physics.

The telemetry panel reads the engine directly every rendered frame: body, contact and wake counts, the exponential moving average of one fixed step, a budget gauge against 60 Hz, and a history plot. Stage attribution is opt-in because measuring it is itself work; with it on, the seven stages sum toward the step cost rather than hiding work in one bucket. Browser clocks are coarsened, so a six-body step can fall below the timer's resolution and read as zero—that is the clock, not the engine.

05 — UNDER THE SURFACE

Built to be questioned.

01 / FIND

Only test plausible pairs.

A dynamic AABB tree prunes distant bodies. The all-pairs path stays in the native tests as a correctness oracle.

02 / RESOLVE

Contacts become impulses.

SAT and clipping generate manifolds. Warm-started sequential impulses resolve friction and contact; joints share the solve loop.

03 / MEASURE

A result needs a boundary.

The recorded native suite contains 142 passing assertions (the older saved receipt had 143; one timing assertion moved to a dedicated benchmark). That is regression evidence—not production certification or a browser performance guarantee.
